# 常见问题

## 为什么安装后提示“还没有规则，无法开始观看”？

Kazumi 安装包不内置任何默认规则。请在首次启动的引导流程中从规则仓库添加至少一条规则，或前往 `我的` → `规则设置`（或 `设置` → `规则管理`）点击 `添加规则`，从规则仓库、剪贴板或本地 JSON 文件导入规则后再开始搜索和观看。若规则仓库加载缓慢，可在 `网络设置` 中开启 `规则仓库镜像`。

## 为什么少数番剧中有广告？

本项目未插入任何广告。广告来自视频源，请不要相信广告中的任何内容，并尽量选择没有广告的视频源观看。也可以在规则高级选项或 `播放设置` 中尝试开启 HLS `广告过滤`。

## 为什么我启用超分辨率功能后播放卡顿？

超分辨率功能对 GPU 性能要求较高，如果没有在高性能独立显卡上运行 Kazumi，尽量选择效率档而非质量档。对低分辨率视频源而非高分辨率视频源使用超分也可以降低性能消耗。

在移动设备上请不要使用质量档超分辨率。

## 为什么播放视频时内存占用较高？

本程序在视频播放时，会在非移动网络下尽可能多地缓存视频到内存，以提供较好的观看体验（移动数据下默认自动开启低内存模式）。如果您的内存较为紧张，可以在 `播放设置` → `低内存模式` 中将其切换为 `始终开启`，以限制缓存大小。

## 为什么少数番剧无法通过外部播放器观看？

部分视频源的番剧使用了反盗链措施，这可以被 Kazumi 解决，但无法被外部播放器解决。

## 为什么下载的 Linux 版本缺少图标和托盘功能？

使用 `.deb` 版本或 Flatpak 进行安装，`.tar.gz` 版本仅为方便二次打包，这一格式先天缺乏图标和托盘功能支持。

## 为什么我的自定义规则无法实现检索或选集？

- **XPath 规则**：Kazumi 的 XPath 选择器需要以 `//` 开头，且 `SearchName`、`SearchResult` 需填写相对于 `SearchList` 的路径，`ChapterResult` 需填写相对于 `ChapterRoads` 的路径。可参考 [XPath 规则开发](/docs/rules/develop-rules) 与 [XPath 规则示例](/docs/rules/develop-rules-example)。
- **API 规则**：Kazumi 使用受限 JSONPath 子集（必须以 `$` 开头，不支持递归 `..`、过滤表达式 `[?(...)]`、切片等）。若搜索接口只返回裸 ID 而选集使用 XPath 解析详情页，需要在搜索规则中配置引用 `@source` 的**详情页地址模板**。可参考 [API 规则开发](/docs/rules/develop-api-rules)。

## 我在尝试自行编译该项目，但编译没有成功。

本项目编译需要良好的网络环境，除了由 Google 托管的 Flutter 相关依赖外，本项目同样依赖托管在 MavenCentral/GitHub/SourceForge 上的资源。如果您位于中国大陆，可能需要设置恰当的镜像地址。
