# 认识 Kazumi

Kazumi 是一款基于自定义规则的跨平台番剧采集与在线观看应用。你可以选择适合自己的规则，在熟悉的设备上搜索和观看番剧。

## 第一次使用，从这里开始

1. [下载 Kazumi](/download)，选择适合设备的版本。iOS 和 HarmonyOS 用户可以先阅读对应的安装指南。
2. [认识规则](/docs/rules/introduce-rules)，了解如何导入、管理与分享内容来源。
3. [探索功能](/docs/intro/module-details)，按自己的习惯设置播放器、弹幕和外观。

遇到安装或播放问题时，可以先查看[常见问题](/docs/misc/qa)。

## 让观看更合心意

Kazumi 支持基于 Anime4K 的实时超分辨率、弹幕、一起看、投屏与硬件加速。你可以在[界面预览](/docs/intro/screenshots)中了解不同主题下的实际外观。

## 想要自己写一条规则？

应用使用 Flutter 开发，支持通过 XPath 选择器描述内容采集方式。你可以从[规则开发指南](/docs/rules/develop-rules)开始，再结合[完整示例](/docs/rules/develop-rules-example)动手实践。

如果内容来源提供 API，也可以阅读 [API 规则开发](/docs/rules/develop-api-rules)。
